# Proposal

## Why

The vault's `Conventions.md` defines item notes, how to resume work and where each fact belongs. Repeating those rules in the plugin has made the copies drift apart.

## What Changes

- Refer handoff completion and vault writing to `Conventions.md` instead of copying its rules.
- Describe the Resume line as how to pick work up.
- Keep convention changes subject to approval in Plannotator and retain plugin README guidance.
- Release the updated plugin as 0.11.13.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `personal-omp-plugin`: delegate item note and vault writing conventions to the vault while preserving handoff and approval obligations.

## Impact

The project handoff and documentation rules, notes skill, accepted specification and release manifests change. No runtime extension code or dependencies change.
