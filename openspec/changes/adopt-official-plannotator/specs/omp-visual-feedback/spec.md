## REMOVED Requirements

### Requirement: Annotation command surface

**Reason**: Plannotator's own OMP plugin, `@plannotator/pi-extension`, owns annotation, and its commands of the same names would be shadowed by this plugin's.
**Migration**: Install `@plannotator/pi-extension` on the host before upgrading. Its `/plannotator-annotate` and `/plannotator-last` replace these commands.
