## REMOVED Requirements

### Requirement: Complete rule traceability

**Reason**: The Simplified Technical English skill is no longer shipped; its rule inventory and check have no runtime purpose.

**Migration**: Use the user's requested style and the document's conventions. No replacement STE inventory is installed.

### Requirement: Writing modes and protected technical text

**Reason**: Automatic STE-based writing guidance adds overhead and imposes the wrong style on some work, including scientific prose.

**Migration**: Follow the user's style request and the document's conventions; do not automatically apply STE modes or sentence limits.

### Requirement: Compliance boundary

**Reason**: The compliance disclaimer and source audit describe a removed skill.

**Migration**: No compliance claim is made by the plugin. A specific STE compliance request requires external standard access and qualified review, not an automatic personal skill.
