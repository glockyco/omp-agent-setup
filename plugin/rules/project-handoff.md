# Project handoff

The owner's `notes` vault has a note for each project, paper and supervision. A note lists its repositories under `links`, and its `Resume here:` line says where the work stands and what comes next.

- When a session works on a project, paper or supervision, find its note. For work in a repository, that is the note whose `links` contain the repository's URL, which a search of `vault://notes/` for the URL finds. Read its `Resume here:` line before you start.
- Before you finish such a session, rewrite the line so that a session with no other context can continue from it: where the work stands and the next step. Add or update dated tasks for steps that have a date. Change and commit the vault as the `notes` skill describes.
- Skip both when no note exists for the work.
