# Compare options

In game projects, such as reference sites and mods, follow the `compare-options` skill before text that players see or a visible design choice ships. This includes posts about them, such as Ko-fi gallery items, and text written inside other work or by subagents, such as a known issue, a label or the reason a value is unknown.
