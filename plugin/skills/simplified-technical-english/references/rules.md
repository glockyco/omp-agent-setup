# ASD-STE100 Issue 9 rule relationships

These are working paraphrases, not official wording. `standard.md` records the official source, checksum, and completed Issue 9 audit. Use the official standard and dictionary for compliance work.

## Section 1: Words

| Identifier | Working paraphrase |
|---|---|
| 1.1 | Use only approved words, technical nouns, or technical verbs. |
| 1.2 | Use an approved word only as its listed part of speech. |
| 1.3 | Use an approved word only with its approved meaning. |
| 1.4 | Use only the approved forms of verbs and adjectives. |
| 1.5 | You can use words that belong to a technical noun category. |
| 1.6 | Use an unapproved word only when it is a technical noun or part of one. |
| 1.7 | Do not use technical nouns as verbs. |
| 1.8 | Use technical nouns approved by your company, industry, or subject field. |
| 1.9 | Select a technical noun that is short and easy to understand. |
| 1.10 | Do not use regional, slang, or jargon words as technical nouns. |
| 1.11 | Use one name for one item. |
| 1.12 | You can use domain verbs as technical verbs. |
| 1.13 | Do not use technical verbs as nouns. |
| 1.14 | Use American English spelling unless another official directive applies. |

Rules 1.1 through 1.4 bind prose to the controlled dictionary. Rules 1.5, 1.6, 1.8, and 1.12 permit necessary technical terms. These terms still have one meaning and one grammatical role.

## Section 2: Multi-word nouns

| Identifier | Working paraphrase |
|---|---|
| 2.1 | Write multi-word nouns of three words or fewer. |
| 2.2 | If a technical noun has more than three words, write it in full. Then give a shorter form or use hyphens between words that act as one unit. |

Break long noun chains with prepositions such as *of*, *on*, *in*, or *for*.

## Section 3: Verbs

| Identifier | Working paraphrase |
|---|---|
| 3.1 | Use only the verb forms that the dictionary gives. |
| 3.2 | Use the infinitive, imperative, simple present, simple past, simple future, or a past participle as an adjective. |
| 3.3 | Use a past participle only as an adjective. |
| 3.4 | Do not use auxiliary verbs for complex constructions. |
| 3.5 | Use an *-ing* form only as a technical noun or in a technical noun. Do not use it as a verb. |
| 3.6 | Use active voice. In descriptive text, passive voice is permitted only when the agent is unknown. |
| 3.7 | Describe an action with an approved verb, not a noun or another part of speech. |

Approved modal meanings use *can*, *will*, and *must*. Replace *may*, *might*, and *could* with *can* for possibility. Replace a required *should* with *must*. Delete a non-factual recommendation or explain why one choice is better.

## Section 4: Sentences

| Identifier | Working paraphrase |
|---|---|
| 4.1 | Write short and clear sentences. |
| 4.2 | Do not omit words or use contractions to shorten sentences. |
| 4.3 | Use a vertical list for complex text. |
| 4.4 | Use connecting words between sentences on related topics. |
| 4.5 | Put an article or demonstrative adjective before a noun when applicable. |

Short text still needs complete grammar. Keep articles and keep *that* when grammar requires it.

## Section 5: Procedural writing

| Identifier | Working paraphrase |
|---|---|
| 5.1 | Use a maximum of 20 words in each procedural sentence. |
| 5.2 | Give one instruction in each sentence unless two actions occur at the same time. |
| 5.3 | Write instructions in the imperative. |
| 5.4 | Put a required condition before the command and separate it with a comma. |
| 5.5 | Notes give information and never instructions. Use the descriptive sentence limit for notes. |

## Section 6: Descriptive writing

| Identifier | Working paraphrase |
|---|---|
| 6.1 | Give information gradually and put only one subject in each sentence. |
| 6.2 | Use key words and phrases to give the text a logical structure. |
| 6.3 | Use a maximum of 25 words in each descriptive sentence. |
| 6.4 | Group related information in paragraphs. |
| 6.5 | Use one topic in each paragraph. |
| 6.6 | Use a maximum of six sentences in each paragraph. |

Descriptions explain. They do not contain imperative instructions.

## Section 7: Safety instructions

| Identifier | Working paraphrase |
|---|---|
| 7.1 | Use a word that identifies the risk level. |
| 7.2 | Start with a clear command or condition. |
| 7.3 | Give an explanation that shows the risk or possible result. |

Use **WARNING** for a risk of injury and **CAUTION** for a risk of damage. The same order applies to destructive commands and irreversible migrations.

## Section 8: Punctuation and word count

| Identifier | Working paraphrase |
|---|---|
| 8.1 | You can use standard punctuation except the semicolon. Use two sentences instead. |
| 8.2 | Use hyphens to connect words that are directly related. |
| 8.3 | You can use parentheses for references, item identifiers, work-step identifiers, abbreviations, singular and plural forms, explanations, or alternatives. |
| 8.4 | In a vertical list, the lead-in colon ends a sentence for word count. |
| 8.5 | Text in parentheses counts as one word. |
| 8.6 | Count each number, number with a unit, abbreviation, identifier, quotation, title, label, or proper noun as one word. |
| 8.7 | Count a hyphenated word as one word. |

Rule 8.6 protects software commands, identifiers, and quoted error text from inappropriate splitting.

## Section 9: Writing practices

| Identifier | Working paraphrase |
|---|---|
| 9.1 | If a word-for-word replacement does not work, restructure the sentence. |
| 9.2 | Use each approved word with its approved meaning and part of speech. |
| 9.3 | Do not build phrasal verbs. Use one approved verb. |
| 9.4 | Keep one style and one set of terms throughout the document. |

General recommendations GR-1 through GR-8 support these rules. Keep *that* when it clarifies grammar. Give pronouns clear referents. Prefer *this* with a noun. Avoid false friends and Latin abbreviations. Use inclusive language. Use a possessive apostrophe only when its meaning is clear.

## Vocabulary discipline

The official dictionary controls approximately 900 approved words and supplies alternatives for unapproved words. It is not reproduced here. Apply these mechanics in pragmatic mode:

- use one word for one meaning;
- use a word as one part of speech;
- select one term for each concept;
- retain necessary technical nouns and verbs;
- use plain replacements only when they preserve the fact.

Common plain substitutions:

| Avoid | Use |
|---|---|
| leverage, utilize | use |
| in order to | to |
| prior to | before |
| ensure | make sure that |
| may, might, could | can |
| should for a requirement | must |
| due to the fact that | because |
| in the event that | if |
| e.g. | for example |
| i.e. | that is |
| etc. | name the items |
| out of the box | by default |

Delete filler that adds no fact. Examples include *simply*, *easily*, *seamlessly*, *robust*, and *state-of-the-art* without measurements.
